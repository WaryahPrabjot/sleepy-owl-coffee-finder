# Sleepy Owl Coffee Finder — Concept Prototype

A small interactive coffee recommendation quiz created as a personal UX/product concept.

## What it does

The prototype asks five simple questions about a customer's:

- Coffee style
- Taste preference
- Desired strength
- Brewing method
- Willingness to try something new

It then recommends one coffee based on the answers.

## Run locally

Open `index.html` in any modern web browser.

## GitHub Pages

This project is designed to work as a static GitHub Pages site. The entry file is `index.html`.
